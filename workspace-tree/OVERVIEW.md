Adds a "Workspace tree" sidebar view that shows each project's workspaces as a collapsible tree. A workspace started from another workspace, for example when an agent spins up separate workspaces for several bugs, appears nested under the one that started it. You can see at a glance which workspaces belong together.

Select it in Settings > Sidebar > Sidebar view. Click a workspace to open it. Click the arrow beside a parent or project to fold it; a folded parent shows how many workspaces it hides. Folded state is saved on this device only.

The dot beside each workspace follows Paseo's status: running, needs input, finished, or failed. A child whose parent has been archived moves to the top level. Workspaces are ordered newest first.
